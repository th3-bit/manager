# Personal Financial Manager - Project Tracker

## 🎯 Project Overview
A personal financial manager web application with the flexibility to be converted into a native mobile app in the future.

## 🛠️ Tech Stack & Tools (Confirmed)
- **Programming Language:** TypeScript
- **Frontend/Mobile Framework:** Expo (React Native for Web & Mobile)
- **Backend/Database:** Supabase
- **Styling:** Tailwind CSS (via NativeWind)

## ✨ Core Features (Confirmed)
- **Core Tracking:** Income vs. Expenses, category tagging (e.g., Food, Rent), monthly budget limits, and savings goals.
- **Loan Management:** Users can add loans and set a monthly payment amount to track progress towards paying them off.
- **Visualizations:** Pie charts by default, with an option for the user to select other chart types.
- **User Accounts:** Multi-user support where anyone can create a secure account.
- **Data Entry:** TBD (We will discuss this later).
